隐私说明

本说明适用于工作书签 Windows 桌面助手及其 Gmail 连接功能，说明程序如何访问、使用、保存和共享 Google 用户数据。

访问哪些数据

Google 登录方式仅请求 https://www.googleapis.com/auth/gmail.readonly 权限，用于读取近期邮件的标识、发件人、主题、接收时间和正文，以识别用户需要的邮件验证码。程序不会申请发送、删除或修改邮件的权限。

用户也可以自行配置 Google 应用专用密码，通过加密的 IMAP 连接读取收件箱。这种凭据本身并不限定只读权限；工作书签只执行读取操作，不连接 SMTP 发信服务、不修改已读标记。

如何使用数据

邮件在用户电脑上解析。程序从近期邮件中识别验证码及有效期，在桌面界面显示候选结果；只有用户点击复制时才将选中的验证码写入本机剪贴板。程序不会利用邮件数据进行广告投放、画像、出售数据或训练 AI 模型。

Gmail 数据的使用遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

如何保存与保护

OAuth 刷新凭据、客户端密钥或应用专用密码使用当前 Windows 用户的 DPAPI 加密保存在本机。连接 Google 时使用 HTTPS 或 TLS 并校验证书。

下载的邮件正文仅用于本次本机解析，不写入产品的内容日志，也不保存邮件附件。验证码候选保留在运行内存中，并按识别出的有效期或默认短期有效期失效，最长识别有效期为 15 分钟。关闭程序会释放这些内存数据；用户自行复制到剪贴板的内容由 Windows 剪贴板管理。

共享与第三方

工作书签直接与 Google 的邮箱和授权服务通信，不通过开发者运营的邮件服务器中转。邮件、验证码和邮箱授权凭据不会发送给 AI 模型或其他第三方。

独立的语音功能默认在本机运行。只有用户明确选择并配置云端语音服务时，才将该次录音或转写文字发送给相应服务；这不会将 Gmail 内容自动加入语音请求。

本说明网站由 GitHub Pages 托管，不包含分析脚本或广告。网站访问本身受 GitHub 隐私政策约束，网站不接收 Gmail 数据。

撤销访问与删除本机数据

用户可在 Google 账号的第三方连接设置中撤销工作书签的 OAuth 访问，也可在 Google 应用专用密码页面撤销相应密码。撤销后，程序无法继续通过该凭据读取 Gmail。

用户可通过工作书签设置中的“本机数据 → 打开数据目录”找到自己的运行数据，关闭程序后移除不再需要的凭据或本机记录。开发者不持有这些本机文件的服务器副本。
